# BridgeLabz Training – Year 2

A Java training and practice repository maintained by **Ujjwal Pratap**. It brings together assisted exercises, self-practice programs, and supporting problem-solving work from the second-year training journey.

## What’s inside

### Assisted Problems
The current folder contains Java exercises such as:

- Adding numbers
- Area of a circle
- Celsius-to-Fahrenheit conversion
- Volume of a cylinder

### Self Problems
The current folder contains independent Java practice programs such as:

- Average calculation
- Kilometres-to-miles conversion
- Power calculation
- Rectangle perimeter
- Simple interest
- Sum of natural numbers

The repository also includes assessment and LeetCode-related folders.

## Repository structure

```text
BridgelabzTraining2Y/
├── Assesment_test/
├── BridgelabzTraining_2Y/
│   ├── Assisted Problems/
│   └── Self_Problems/
├── LeetCode_Qn/
└── Self practice/
```

## Run a Java program

Install a JDK and compile a selected source file:

```bash
javac simpleinterest.java
java simpleinterest
```

The class name may differ from the filename in other exercises; use the class declaration in each file.
